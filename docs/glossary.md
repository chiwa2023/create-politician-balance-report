# 用語集

## 1.名付け規則

a.基本的には英語を使用。日本語(ローマ字)も使用可能。複数記述法の利用も可。ただし「かなの省略」の発生する記述方式は可読性が極端に落ちるのでNG
ex.様式区分
×yoshikikbn
〇yohsikiKbn
〇youhshikiKbn
